# Host the privacy policy

The source is `docs/privacy.html`. Google Play requires a public HTTPS privacy-policy URL, not a repository source-file URL.

Option: enable GitHub Pages in the repository settings, select **Deploy from a branch**, branch **main**, folder **/docs**, and save. Once deployed, the expected URL is:

https://modealpha88-ctrl.github.io/BudgetTracker/privacy.html

**Verify the page actually loads in an incognito browser** before entering it into Play Console. The URL above is an expected address, not proof of a live deployment.

Before publication, replace the GitHub Issues-only contact route with a dedicated support email and check the policy against the actual app and third-party SDKs. Do not include private financial data in public support issues.
